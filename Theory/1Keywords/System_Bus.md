# System Bus
- 컴퓨터의 핵심 부품인 CPU, 주기억장치(RAM), 그리고 입출력 장치(I/O) 간에 정보(데이터, 주소, 제어 신호)를 주고받는 통로(데이터 고속도로).
- 버스를 통한 데이터 전송 속도가 시스템 전반의 처리 성능을 좌우.

## Adress Bus
- 데이터를 읽거나 쓸 때, 그 데이터가 위치한 기억 장소(주소)를 지정하는 통로.
- 특징:
	- CPU가 주기억장치나 입출력 장치로 보내는 단방향 통로.
	- 주소 버스의 크기에 따라 CPU가 인식할 수 있는 최대 메모리 용량이 결정.
## Data Bus
- 컴퓨터에서 처리될 실제 데이터가 이동하는 통로.
- 특징:
	- CPU, 메모리, 주변장치 사이 양방향 이동.
	- 데이터 버스의 대역폭(비트 수)이 넓을수록 한 번에 더 많은 데이터를 처리.

## Control Bus
- 컴퓨터 부품들의 동작을 지시하고 상태를 전달하는 통로.
- 특징:
	- CPU가 메모리나 입출력 장치에 "읽기(Read)" 또는 "쓰기(Write)" 동작을 지시하는 신호 등을 양방향으로 전송.

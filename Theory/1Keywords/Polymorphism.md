# 다형성(Polymorphism)
- 하나의 객체나 함수가 여러 가지 형태로 동작할 수 있는 성질
- 같은 명령인데 실제 객체에 따라 다르게 동작하는 것
- 부모 타입 변수가 여러 종류의 자식 객체를 담아 같은 방식으로 사용하되,<br>
실제 동작은 객체의 타입에 따라 달라지는 것
- 코드의 유연성을 높이고, 새로운 기능을 가진 클래스를 추가하기 쉬운 구조로 만들 수 있다.

#### virtual
- 부모 클래스 함수에 붙이는 키워드
- 해당 함수를 자식 클래스에서 override로 재정의할 수 있게 허용한다.

#### override
- 부모 클래스의 virtual 함수를 자식 클래스에서 다시 구현할 때 사용하는 키워드
- 같은 함수 호출이라도 실제 객체의 override 함수가 실행된다.

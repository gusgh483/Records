# CBD(Component Based Development)
- 소프트웨어를 처음부터 다 만드는 대신, <br> 
독립적으로 개발된 재사용 가능한 소프트웨어 모듈(컴포넌트)들을 조립하여<br> 
새로운 애플리케이션을 구축하는 개발 방법론입니다. <br> 
마치 레고 블록을 맞추어 장난감을 완성하는 것과 같습니다.<br> 
## 주요 특징 및 개념
- 컴포넌트(Component): 특정 기능을 수행하는 독립적인 소프트웨어 부품으로,<br> 
인터페이스(API 등)를 통해 다른 모듈과 소통합니다.<br> 

- 조립과 재사용: 이미 검증된 컴포넌트를 재활용하므로 개발 시간과 비용을 줄일 수 있습니다.<br> 
- 유지보수 용이성: 특정 기능에 문제가 생기면 해당 컴포넌트만 수정하거나 교체하면 되므로 관리가 쉽습니다.<br> 
- CBD의 핵심 장점생산성 향상: 코드 전체를 작성하지 않고 부품을 조합하여 빠르게 개발합니다.<br> 
- 품질 보증: 검증된 기성 컴포넌트를 사용해 오류 발생 확률을 낮춥니다.<br> 
- 유지보수성: 문제 발생 시 해당 블록만 분리하여 수정이 가능합니다.

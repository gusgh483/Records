# 명령어 사이클(Instruction Cycle)
- CPU가 메모리에서 프로그램의 명령어를 하나씩 가져와(인출) 해독, 실행하는 일련의 반복 과정.
- 컴퓨터가 프로그램을 실행하고 구동하는 가장 핵심적인 기본 단위.

## 인출 사이클(Fetch Cycle)
- CPU가 실행할 다음 명령어를 메모리에서 CPU 내부(명령어 레지스터)로 가져오는 단계.

## 간접 사이클(Indirect Cycle)
- 명령어에 실제 데이터 값이 아닌 '데이터가 저장된 메모리 주소(포인터)'가 포함되어 있을 때,
- 해당 주소로 접근하여 실제 데이터를 한 번 더 찾아오는 단계.

## 실행 사이클(Execution Cycle)
- 가져온 명령어를 해독하고, 그 내용에 따라 연산 장치(ALU)를 통해 실제 작업을 수행하는 단계.

## 인터럽트 사이클(Interrupt cycle)
- 실행 사이클이 끝난 후, 예외 상황(오류 발생, 입출력 요청 등)이나 우선순위가 높은 작업이 발생했는지 확인하고 이를 처리하는 단계.
- 이 과정은 컴퓨터의 전원이 켜지는 순간부터 꺼질 때까지 아주 빠른 속도로 끊임없이 반복.
- 더 자세한 내용과 컴퓨터 구조 원리는 위키백과 명령어 주기에서 확인 가능.

# Wav
- 마이크로소프트와 IBM이 만든 WAV - 위키백과 표준 오디오 파일 형식.
- 소리를 줄이지 않고 원본 그대로 저장해 최고 수준의 음질을 내지만, 파일 용량이 매우 큽니다.
- .WAV 파일의 특징
    - 최고의 음질: 소리 손실이 전혀 없습니다.
    - 큰 용량: 압축을 하지 않아 파일 크기가 큽니다.
    - 높은 호환성: 윈도우 및 다양한 소리 편집 프로그램에서 바로 쓸 수 있습니다.
 
- MP3와의 차이WAV 
    - 원본 그대로 저장하여 음질이 가장 좋으나 용량이 큽니다
    - .MP3: 소리를 압축하여 음질은 조금 떨어지지만 용량이 매우 작습니다.

# 파일 포맷(File Format)
- 컴퓨터에 데이터를 저장하고 읽기 위해 정보를 인코딩하는 방식.
- 문서, 이미지, 오디오 등 데이터의 종류에 따라 적합한 확장자를 사용해야 하며, 파일의 용도와 특징에 맞게 선택.

- 1. 문서 및 텍스트
    - PDF: 문서 원본 형태를 그대로 유지하여 공유할 때 사용
    - TXT: 서식이 없는 가장 기본적인 텍스트
    - 문서
        - DOCX / HWP: 워드프로세서(MS Word, 한글) 전용 문서
- 2. 이미지
    - JPG / JPEG: 사진 등 색상이 많은 이미지에 적합하며 용량이 작음
    - PNG: 배경을 투명하게 만들 수 있으며 선명한 그래픽에 적합
    - GIF: 짧은 애니메이션(움짤)이나 단순한 색상의 이미지에 사용

- 3. 비디오 및 오디오
    - MP4: 유튜브 등에서 가장 표준으로 사용되는 동영상 포맷
    - MP3: 압축률이 높아 음악 감상에 가장 널리 쓰이는 음성 포맷
    - WAV: 압축하지 않아 음질이 뛰어나지만 용량이 큰 오디오


포맷데이터를 읽거나 수정하려면 해당 포맷을 지원하는 전용 프로그램이 필요합니다.

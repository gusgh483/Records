# Tga(Truevision TGA)
- 고품질 이미지와 투명도(알파 채널) 정보를 손실 없이 저장하기 위해 만든 래스터 그래픽 파일 형식.
- 주로 게임 그래픽, 3D 텍스처, 동영상 편집에서 원본 화질을 유지하려고 많이 씁니다.
- TGA 파일의 특징
    - 무손실 압축 및 고화질: 화질 저하가 없어 선명한 그래픽 데이터를 유지합니다.
    - 알파 채널 지원: 배경이 투명한 이미지를 만들 때 유용합니다.
    - 큰 용량: 압축률이 낮거나 압축하지 않아 파일 크기가 큰 편입니다.

# Png(Portable Network Graphics)

- 투명한 배경을 지원하고 화질 손실 없는 무손실 압축을 제공하는 이미지 파일 확장자.
- 로고, 아이콘, 텍스트가 포함된 그래픽이나 웹 디자인에 주로 사용
- 일반 사진용인 JPG보다 용량이 큰 편.
- 주요 특징 및 장단점
    - 투명 배경 지원: 알파 채널을 지원하여 이미지 배경을 투명하게 만들 수 있습니다.
    - 무손실 압축: 데이터를 압축할 때 원본 이미지가 훼손되지 않아 선명함을 유지합니다.
    - 적합한 용도: 선명한 그래픽, 로고, 일러스트.
    - 주의 사항: 일반 사진을 PNG로 저장하면 JPG보다 용량이 매우 커질 수 있습니다.

# BMP
- BMP는 윈도우에서 만든 그림 파일 형식. 색을 픽셀 단위로 그대로 저장. (화질 ↑, 크기 ↑)
- DIB(Device Independent Bitmap)라고도 하는 BMP 파일은 비트맵을 의미하며, 범프(Bump)라고도 불립니다.
- BMP 파일의 특징
    - 그림을 압축하지 않고 그대로 저장.
    - 화질이 선명하고 깨지지 않습니다.
    - 파일 크기가 너무 커서 인터넷 웹사이트에는 잘 쓰지 않습니다.
    - 포토샵이나 윈도우 사진 앱 등에서 쉽게 열 수 있습니다.

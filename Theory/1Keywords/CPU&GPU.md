# CPU와 GPU의 차이

## 중앙처리장치: CPU(Central Processing Unit)
- 복잡한 작업을 순차적으로 빠르게 처리하는 컴퓨터의 두뇌

## 그래픽처리장치: GPU(Graphics Processing Unit)
- 단순한 작업을 대량으로 동시에 처리하는 병렬 연산 장치


## 차이
| 구분 | CPU | GPU |
|---|---|---|
| 핵심역할 | 컴퓨터 전체 시스템 제어 및 제어 흐름 관리 | 대규모 그래픽 렌더링 및 고속 연산 가속 |
| 처리방식 | 직렬 처리 (한 번에 하나씩 순차 수행) | 병렬 처리 (수많은 작업을 동시 수행) |
| 코어구조 | 성능이 뛰어난 소수의 고성능 코어 (4~64개) | 단순 연산에 특화된 수천 개의 작은 코어 |
| 강점분야 | 복잡한 논리 연산, 데이터 제어, 단일 작업 속도 | 단순 반복 계산, 대용량 데이터 동시 처리 |

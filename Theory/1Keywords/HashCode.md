# 해시코드 (Hash Code)
- 정의
	- 객체를 식별하기 위해 고유하게 부여되는 정수 값
	- 주로 Dictionary나 Hashtable과 같은 해시 기반 컬렉션에서 <br>
      데이터를 빠르고 효율적으로 찾기 위한 인덱스(키)로 사용
- 특징
	- GetHashCode():객체의 HashCode값을 계산하여 가져오는 함수
	- 변환 타입: 32bit 부호 있는 정수(int)값 반환
	- 해시값은 기본적으로 객체의 일생동안 바뀌지 않는다.<br>
      기본 메서드는 object의 GetHashCode()를 사용하나,<br>
	  클래스나 자료구조별로 재정의가 되어있을 수 있다.

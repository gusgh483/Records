### 26.10.13
#### [회의 내용]
1. 상점 클래스 설계 - from 이민곤
- 플레이씬(최고 관리자)<br><br>

- 샵 클래스:<br>
	- 상점 아이템 데이터를 배열 들고있음<br><br>

- 샵뷰 클래스: <br>
	- 샵 클래스를 필드로 들고있거나 <br>
      샵 슬롯뷰를 배열로 들고있다가<br>
      샵 클래스의 데이터를 가지고 샵슬롯뷰 배열을 순회하면서 쇼 함수를 실행<br><br>

- 샵 슬롯뷰 클래스:<br>
	- 필드, 이미지 아이템 아이콘, 문자열 아이템 이름, float 아이템 가격<br>
	- 퍼블릭 쇼함수(문자열 아이템 아이디or 아이템 데이터) <- 온클릭 함수<br>

- 샵 데스크뷰 클래스(필요시)<br>

- 전달받는 함수: 샵 클래스에 퍼블릭 구매 함수<br>

2. 씬별 이름
- 선상 씬: BoardScene
- 낚시 씬: TreasureScene
- 초밥 씬: IzakayaScene

3. 수정 및 제외할 뷰
- 수중 적재 기능에 따른 적재 뷰 삭제
- 초밥집 씬 요리 강화 기능에 따른 요리 강화 뷰 삭제

- 인벤토리 뷰: 해저탐험 시의 인벤토리 기능을 잠구고<br>
               스마트폰(공통 씬 기능)으로 변경하여 인벤토리 뷰 하나로 통합<br>
               할일(미션) 앱 활성화 시 출력되는 방향 (★상의 필요)

- 탐험 결과 뷰: 온도, 날씨, 플레이타임, 탐험한 깊이 정보 제외
	- 개인적인 의견<br>
	=> 상단: 탐험 성공 및 실패 이미지<br>
	=> 중단: 잠수 회차, 날짜, 포획 수, 아이템 획득 수 텍스트<br>
	=> 하단: 획득한 아이템 목록 (탐험 실패 시 1개만 선택 가능 하도록)<br>  

- 스마트폰 뷰: 앱 출력 방식 변경 의견 제시(★상의 필요)

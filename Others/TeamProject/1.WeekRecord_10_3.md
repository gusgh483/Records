### 26.10.12
#### [회의 내용]
<br><br>

1. 선상 씬 뷰 기능

- 기본 UI
	- 보유중인 골드 재화 표시
		- 골드 아이콘 이미지
		- 보유중인 골드량을 표시할 텍스트
	- 진행중인 퀘스트 목록
		- 분류별 퀘스트 아이콘 (메인, 서브, 콘텐츠)
	- 잠수 아이콘 (활성화 시 잠수 씬으로)
	- 날씨 아이콘과와 날짜
	- 현재 어느 시간대를 보내고있는지 나타내는 시간표
	- 스마트폰 아이콘 (활성화 시 스마트폰 UI)

- 스마트폰 내부 UI
		- 우선 구현할 앱 ５종
			1) 할 일
		    2) 메일
		    3) 날씨
		    7) 설정
		    5) 다이버샵
		- 의논할 앱 ５종
		    4) 웨폰샵： 웨폰 샵에서 구매도 포함인지、 오직 업그레이드만인지
		    6) 일반상점： 웨폰 등 업그레이드 요소도 구매 기능을 구현하는지 
		- 후순위 구현할 앱 2종
		    1) 업적
		    2) 컬렉션

- 후순위 구현할 뷰
	- DiveLog（낚시 후 선상으로 돌아와 정산하는 뷰）

#### [개인작업]
<br><br>

- 오늘의 대화 분석
	- UI 의견 모음
		1) 화면에 비출 그래픽적인 요소가 먼저 확인이 되지 않으면 UI와 조화를 헤칠 우려가 있음을 제기.<br>
		-> 이민곤 조장님이 에셋을 활용하여 간단한 배경 연출 이미지를 보내주는 것으로 일단락.<br>
		= 추후 전반적인 UI 분위기가 확정되고 에셋 제작에 박차를 가할 것으로 기대.<br>

	    2) 개발 기간 단축을 위해 상점 기능을 하나로 통합하는 방안 제시.<br>
		-> '구매'와 '업그레이드' 두 기능이 분리되어 UI를 따로 둬야할지...(자세한 사항은 평가 일정이 끝난 후 결정)<br>
		= 개인적인 의견: 하나의 상점 앱으로 통합 후 카테고리를 나누며<br>
		  특별상점의 경우 SALE 카테고리를 따로 추가(SALE 기간이 아닐 때는 세일 기간이 아니라는 문구와 함께 빈 페이지 출력)<br>

		3) UI 배치 및 움직임에 따른 변화 등의 작업 결정권 여부.
		-> 최대한 UI 에셋 개발 인원들의 의견을 적극 반영하기로.

# 취업특강 (2026.07.23)

## 공고 확인
- 게임잡 / 잡코리아 (게임 쪽 아니어도 취업 희망 - 사람인, 원티드)
- 네이버에 게임 관련 채용 공고 검색
- 지원요건, 담당업무, 우대사항(중요) - 자소서 어필 가능, 지원자격(중요)
- 주로 어떤 쪽으로 많이 뽑는지 분석 (추세: 장르적-RPG / 플렛폼-모바일)
- 잘 모르겠으면 회사 홈페이지를 방문하여 참고(추구하는 슬로건, 인재상 등의 상세내용)
- 신입 외 경력무관/3년차(실력만 충분하다면 비벼볼만) 까지도 확인
-  구인 업체 리스트 업: 내게 어떤 문제가 있는지 알아내기 위해

## 포트폴리오
- 추천 게임 장르: RPG
- 그래픽 요소 무시 못함: 지금부터 고려
- 인게임(플레이) 외에도 구현할 것 <= 완성된 게임
- 플로우차트 작성으로 게임 전체적 흐름 인지(간단하게라도)
- 확장성(꾸준한 업데이트) 고려해서 개발
- 구조가 명확하고 버그 없이 정리된 프로젝트
- 대표 프로젝트에 기본적으로 넣어야 할 가능 - 조작, 전투, 상호작용 , 적AI, UI, 게임 흐름, 데이터 관리, 저장 기능, 오브젝트 풀링, 빌드 파일
- QA까지 기간에 포함.
- 트러블슈팅: 특정 문제에 대해 / 회고 및 개선점은 전체적으로 느낀 것
- 문서작성 시
	- 최대한 한번에 볼 수 있도록 간결하게(지저분하고 복잡하지 않게)
	- 구현한 사실 뿐만이 아니라 왜 구현했는가(사고력)
	- 결과 외 중간 과정에서 발생한 문제 해결 사례 언급
	 ㄴ 문제상황 - 원인분석 - 해결방법 - 적용결과 - 배운점

## 이력서
- 이력서에 포트폴리오 노션 링크등 기재(PDF 대체) - 제출 시 꼼꼼히 내용 읽어볼 것
- 이력서에 비어있는 공간은 지우기
- 게임 테스터 참여 이력도 넣어도 좋다
- 자격증, 어학능력/대외할동등 적을 내용 없으면 걍 삭제
- 도저히 적을 것이 없다면 어떤 게임을 얼마나 했는지 플레이 이력 기재(특히 기획자)

## 자소서
- AI 금지: 인사담당자가 보지도 않고 떨굼 (참고만 할 것)
- 경력사항(경험사항): 
	- 경력이 있다면 해당 직무 아니어도 상관없지만<br>
	그것을 통해 얻은 것들을 해당 직무와 연결시켜 도움이 될지 작성
    - 주로 팀프로젝트(어떤 문제가 있었고 어떻게 대처했는지)
	- 인성에도 연결될 수 있음
- 성장과정: 왜 내가 이런 쪽으로 지원하게 되었고 무엇을 했는지 (어린시절 안궁금함)
- 성격 장점: 난 어느 회사 가도 어울릴 수 있다는 어필 (회사에 적합한 인재상)
- 단점: 업무엔 지장 없지만 개선해야할 점(구체적으로 적지 말자 - 스치듯 작성)
- 지원 동기: 업계에 대한 이해도 어필(회사에서 추구하는 방향과 맞다는 것)
- 포부: 초기/중기/장기 (신입으로써 해야할 일이 무엇이 있고, 하고싶은 것이 무엇이 있는지, 회사 방향과 맞지 않으면 따를 의향 등)
- 게임 개발 이력: 포트폴리오 내용도 ok
- 게임을 유저 입장이 아닌 개발자 입장으로 바라볼 것
- 너무 길게는 x (포인트만 - 과하지 않은 선에서 영어같이 눈에 띄는 부분 활용)

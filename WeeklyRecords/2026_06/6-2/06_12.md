## Unity
- Random.insideUnitCircle 
	- 0~1까지의 크기를 가진 가상의 원을 그리고 무작위로 점을 찍는다.
	- normalized를 통해 크기를 1로 고정시켜 단위벡터로 만들어 방향을 구할 수 있다.

## Math

## Code
```
// 랜덤 방향 구하기
Vector2 dir;

// 1) 유니티 함수 사용
dir = Random.insideUnitCircle.normalized;

// 2) 삼각함수 사용
float angle = Random.Range(0, 2 * Mathf.PI); // 각도(radian)
dir = new Vector2(Mathf.Cos(angle), Mathf.Sin(angle));
```
